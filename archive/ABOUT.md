# Bitcoin Cash Daemon — BCHD full node on StartOS

BCHD — Go-based Bitcoin Cash full node with gRPC and Neutrino

BCHD is a full node implementation of the Bitcoin Cash protocol written in Go. Features include JSON-RPC API, gRPC API with pub/sub notifications, BIP 157/158 compact block filters (Neutrino), BIP 37 bloom filters, full transaction and address indexes, and Tor support for private peer connections.
